# 健身私教课预约管理系统-python
### 1、系统功能
健身私教课预约管理系统，采用前后端分离架构。后端基于Python FastAPI，前端基于Vue3 + Element Plus，数据库使用MySQL，实现从会员管理、教练管理、课程管理、排课管理、预约管理到课时记录的全流程闭环！

· 登录

· 首页（仪表盘数据统计）

· 会员管理

· 教练管理

· 课程管理

· 排课管理

· 预约管理

· 课时记录

· 系统管理：菜单管理 | 角色管理 | 账号管理
